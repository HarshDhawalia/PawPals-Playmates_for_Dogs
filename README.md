PawPals 🐾

A Tinder-inspired responsive web application for dogs to meet new friends and playmates.
The project focuses on front-end fundamentals, responsive UI design, and adapting a popular swipe-based interface for a non-dating, friendship-oriented use case.

CSS3

JavaScript

📦 Features

Swipe-style card layout inspired by modern social apps

Fully responsive design (mobile, tablet, desktop)

Clean and intuitive UI

Lightweight static website with fast load times

Dog-friendly concept focused on socialization, not dating
